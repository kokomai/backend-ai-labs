# 변경 요청 센터 완료 검증

1. 완료라고 보고할 항목마다 어떤 관찰로 확인할 수 있는지 정한다. 빌드는 컴파일과 패키징을 확인하고, API·MCP 동작은 실행 중 응답을 확인하며, 브라우저 사용성은 브라우저에서 확인한다.
2. 최신 변경으로 해당 검증을 실행하고 종료 상태와 실제 출력 또는 화면 응답을 확인한다. 검증 결과가 기대와 다르면 오류를 좁혀 다시 확인한다. [프로젝트 스모크 검증](../change-advisor-smoke-test/SKILL.md)에서 변경에 해당하는 시나리오를 고른다.
3. 완료 보고에 검증 방법과 실제 결과를 기록한다. 실행하지 못한 항목은 환경이나 자격 증명 등 구체적인 사유를 남긴다. 외부 모델을 모의 서버로 확인했다면 그 범위를 명시한다.

Superpowers의 결과를 확인한 뒤 완료를 보고하는 절차를 프로젝트에 적용했다. [원본 고정 리비전](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/verification-before-completion/SKILL.md)
