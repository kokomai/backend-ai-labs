# 변경 요청 센터 작업 계획

[프로젝트 현황](../../../PROJECT.md)에서 기존 기능과 후보를 확인하고 중복 작업을 찾는다.

- 현업과 개발자 중 누가 어떤 화면에서 무엇을 할지 적는다. 요청을 관찰 가능한 화면 결과, API 응답 또는 상태 전이로 바꿔 수용 기준을 만든다.
- 화면 변경, 분석·저장 계약, 독립 검증의 의존성을 확인하고 해당하는 역할을 지정한다. 작은 작업은 한 범위에서 처리한다.
- 승인된 요청과 추가 조사 후보를 구분한다. 범위를 바꾸는 선택지는 결정 근거와 영향을 남긴다.
- 새 프로젝트 항목을 만들거나 기존 항목의 범위를 바꾸는 작업이면 `PROJECT.md`를 갱신한다. 작업 기록에는 확인 결과나 검증이 남은 이유를 적는다.
